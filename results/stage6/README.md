# Stage6 Results

This directory is reserved for commit-friendly Stage6 summaries generated by
`scripts/run_stage6_posttrain_autopilot.sh`.

Expected generated artifacts:

- `posttrain_summary.json`: machine-readable training, Nsight Compute, and
  six-task evaluation summary.
- `posttrain_summary.md`: human-readable summary for the model card, report, and
  release notes.

Raw logs, Nsight Compute reports, and lm-eval sample dumps stay under
`logs/`, `runs/`, and `eval_results/`, which are intentionally ignored by Git.
