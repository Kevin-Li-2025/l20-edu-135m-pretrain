# Results

This directory contains curated, commit-friendly result summaries. Raw
benchmark sample dumps and full run directories are excluded from Git.

- [benchmark_comparison.csv](benchmark_comparison.csv): six-task comparison
  against public baselines.
- [benchmark_comparison.json](benchmark_comparison.json): machine-readable
  version of the same comparison.
- [stage4/](stage4/): selected Stage 4 checkpoint, data gate, and SFT regression
  summaries.
- [rlvr/](rlvr/): GSM8K exact-match summaries and the recorded RLVR c320
  decision.

The canonical narrative lives in
[../docs/project_report/TECHNICAL_REPORT.md](../docs/project_report/TECHNICAL_REPORT.md).
