# Paper

This directory contains the arXiv-style project write-up:

- [l20_edu_135m_arxiv.pdf](l20_edu_135m_arxiv.pdf): compiled paper draft.
- [l20_edu_135m_arxiv.tex](l20_edu_135m_arxiv.tex): LaTeX source.
- [references.bib](references.bib): bibliography.

The paper frames L20-Edu-135M as an auditable single-GPU, data-efficient
small-language-model study. It does not claim state of the art; it emphasizes
token-budget transparency, data filtering, benchmark comparability, and the
negative RLVR result.
